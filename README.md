# Drift Beacon: Home Assistant add-on

Runs a Drift Beacon hub on your Home Assistant host.

[![Add repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fdrift-beacon%2Fha-app)

Or add `https://github.com/drift-beacon/ha-app` under Settings → Add-ons → Add-on store → ⋮ → Repositories, then install **Drift Beacon**. See [DOCS.md](drift-beacon/DOCS.md) for its options.

To use Drift Beacon from Home Assistant (devices, actions, triggers), install the integration too: [drift-beacon/ha-integration](https://github.com/drift-beacon/ha-integration). It works with this add-on or with a hub running elsewhere.
